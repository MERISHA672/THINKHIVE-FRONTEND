# ThinkHive Frontend 🧠

ThinkHive is a learning and community platform designed to help students, educators, and lifelong learners learn together, share ideas, and grow their knowledge.

The frontend provides the main user interface of the ThinkHive platform. It was developed using React and Vite with a focus on creating a simple, modern, and user-friendly learning experience.

> **Learn together. Think bigger.**

---

## 📌 Project Overview

ThinkHive brings learning and community interaction into one platform.

Users can explore available courses, participate in discussions, and learn from different educational resources.

The frontend contains the main pages and interactive features that users interact with when using ThinkHive.

---

## ✨ Main Features

### 🏠 Home

The homepage introduces ThinkHive and explains the purpose of the platform.

It provides users with an overview of the platform and its main benefits:

- Learn
- Connect
- Grow

---

### 👥 Community

The Community section allows users to interact and share ideas.

It includes:

- Discussions
- Search functionality
- Discussion categories
- Post creation
- Community conversations

The goal is to create a space where learners can ask questions, share knowledge, and interact with other users.

---

### 📚 Courses

ThinkHive provides different learning courses that users can explore.

Some of the available courses include:

- **Introduction to Web Development** – 12 lessons
- **SQL & Database Fundamentals** – 10 lessons
- **Python Programming Essentials** – 15 lessons

The courses section is designed to help users discover learning materials in different areas of technology.

---

### ℹ️ About

The About section explains the purpose of ThinkHive and the idea behind creating a platform that combines learning with community interaction.

---
